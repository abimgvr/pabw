# pabw
Pembelajaran Pengembangan Aplikasi Berbasis Web
## Pertemuan 4 — Halaman profil saya

Topik halaman saya: kegiatan saya sebagai anggota Mapala UNISI di empat
divisi kepetualangan.

- Judul halaman: Abimanyu Maheswara — PABW 2026/2027
- Deskripsi: tentang saya, perjalanan di Mapala, karya, keterampilan, dan kontak
- Tautan navigasi: Tentang, Karya, Kontak
- Struktur tambahan: lini masa perjalanan di Mapala, daftar keterampilan
  dari lapangan, dan tanya jawab seputar kegiatan Mapala
- Gambar: foto-profil.jpg

### Arah visual

Arah visual: tenang dan akademik, dengan warna hijau lumut — dipilih
karena warna ini identik dengan alam dan kegiatan lapangan Mapala UNISI
tempat saya aktif.

### Design token yang saya tetapkan

| Token | Nilai | Untuk apa |
|---|---|---|
| --color-primary | #2F4A3D | tombol, tautan, judul bagian |
| --color-fg | #1B241E | warna teks utama |
| --color-bg | #F7F9F7 | latar halaman |
| --color-focus | #B45309 | garis fokus papan ketik |
| --radius-md | 0.5rem | sudut tombol dan kartu |
| --space-4 | 1rem | jarak standar antar elemen |

Kriteria selesai saya: mengubah --color-primary di satu baris tokens.css
harus mengubah warna tombol, tautan, judul, dan garis fokus.

## Catatan penggunaan AI

Saya dibantu Claude untuk menyusun kode HTML dan CSS (pengisian penanda,
tiga struktur tambahan, lima berkas CSS, dan tema gelap) berdasarkan
arah visual dan topik yang saya tentukan sendiri (Mapala UNISI, warna
hijau lumut). Rencana isi dan keputusan warna adalah milik saya sendiri.
